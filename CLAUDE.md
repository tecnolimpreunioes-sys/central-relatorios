# Instruções do projeto

## Pacote para PROD
Ao entregar arquivos para subir em produção:
- Um zip por máquina (VM Ubuntu, tecnolimp15, TECNOLIMP12) + `PASSO-A-PASSO.md` com a ordem.
- **Na resposta do chat**, para cada passo: máquina, shell (PowerShell Admin / bash via ssh) e os comandos prontos para colar, já com os caminhos reais, mais o resultado esperado e como voltar atrás.
- Migration antes do site quando o frontend depende dela.
- Nunca incluir `config.js` da produção nem `credenciais.bat`.
